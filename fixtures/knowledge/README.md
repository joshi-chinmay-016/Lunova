# Knowledge Base Fixtures (`fixtures/knowledge`)

This directory is reserved for **synthetic, test-only knowledge documents** used for offline RAG benchmarking, integration testing, and local evaluation.

---

## Intended Fixture Categories (Future)

When representative documentation is prepared, synthetic fixtures will cover:
- **Company Profile**: High-level synthetic mission, headquarters, and operational overview.
- **Services**: Generic software architecture, integration, and platform engineering offerings.
- **Technologies**: Supported standard protocols (e.g. REST, OAuth2, Webhooks, PostgreSQL).
- **Case Studies**: Anonymized, synthetic delivery narratives illustrating response formatting.
- **FAQs**: Common RFP questions and standard synthetic answers.
- **Proposal Examples**: Golden reference responses for regression testing.

---

## Important Rules

> [!CAUTION]
> **No Fabricated Lunetron Claims**:
> - Do **not** invent fake Lunetron capabilities, client logos, certifications, pricing models, or delivery schedules in test fixtures.
> - Real Lunetron proprietary knowledge will only be incorporated once Lunetron formally provides verified and approved source materials.
> - All knowledge files in this folder must remain synthetic, sanitized, or explicitly cleared for testing.
